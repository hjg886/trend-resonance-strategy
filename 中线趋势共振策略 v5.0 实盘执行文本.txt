  2. 每笔真实建仓须与模拟盘决策一致，不一致时以模拟盘为准复盘
  3. 首月建仓额度减半执行（过渡期风险预算）

二、执行选股指令（全市场扫描优选 · 候选池生成源）
【指令宗旨】候选池只由"全市场优选"产生：先在尽可能广的样本里筛出优秀标的（国家赛道 / 政策赛道、龙头股等），唯有通过质量门的优秀标的才进入候选池；禁止把未经理优、随手列示的标的直接入池。与核心设计哲学①（进股市投资目的=赚钱，<12%硬约束下最大化收益）及【优化修正出发点·持久原则】（不断优化修改提高收益率+科学风控）一致。

1. 扫描范围（全市场，不预设白名单）
- 个股主进攻线：全A股（沪/深主板、创业板、科创板；北交所仅作观察不主配）。剔除：B股、ST/*、退市风险、流动性枯竭（日均成交<5000万 或 流通市值<50亿）。
- ETF防守辐：全市场 ETF 池（宽基 / 行业 / 债券 / 货币），按产品健康度 E-P0.0 初筛。
- 数据源：东方财富 Choice / westockdata（K线、财务、行业、赛道标签、RPS/R值、成交）。

2. 优秀标的判定维度（开放式漏斗：入口放宽、出口收紧；以下为加权排序 + 质量门，非层层硬否决）
- ① 国家赛道 / 政策赛道（高权重）：属国家战略性新兴产业、新质生产力、六大新兴支柱产业、政策白名单方向，有明确产业趋势与政策催化。
- ② 龙头地位：行业龙头或细分龙头（营收 / 市占率 / 龙头评级居前）——"赚行业成长的钱，也赚个股趋势精选的钱"。
- ③ 趋势健康（TRE）：目标 TRE ∈ {S2, S3}；股价站 MA60 上方且偏离合理（非极端泡沫偏离）；ADX 趋势明确。
- ④ 财务健康（层级1 不暴雷）：营收同比>0、净利同比>0、经营现金流同比>0、ROE 达标、现金/净利润健康；任一层级1暴雷 → 一票否决不入池。
- ⑤ 流动性与规模：日均成交额≥5000万、流通市值≥50亿；成交活跃、无流动性陷阱。
- ⑥ 估值/成长匹配：估值作排序/仓位参考（拒绝泡沫接盘、不僵化低估）；成长与估值匹配度优先。
- ⑦ 相对强度：RPS 高（≥70 阶梯，越高越优）；R值 非C（R值/RPS 仅降权不否决）。
- ⑧ 情绪正向：情绪溢价正向、无重大负面舆情 / 监管风险。

3. 评分与入池门槛（唯有"优秀 + 过质量门"的标的入池）
- 个股：24因子综合得分 ≥70（#167 口径）方可入候选池；以 A+/A（常规≥80）为主进攻线核心；B级仅观察不分配。
- ETF：13因子 宽基≥75 / 行业ETF≥78 入池；产品否决 E-P0.0 一票否决。
- 真风险层一票否决（直接不入池）：层级1财报暴雷 / ETF产品否决E-P0.0 / 持仓阶段P2-P3。
- 排序：候选池按综合得分降序（见三、候选标的清单）；得分越高越优先进入建仓裁决。
