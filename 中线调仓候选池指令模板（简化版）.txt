# 中线调仓候选池指令模板（v5.0 A股为主·ETF为辐·开放式漏斗版 · 优化修正版）

基于《中线趋势共振策略_v5.0.txt》（A股为主·ETF为辐·开放式漏斗版），保留24因子/13因子评分体系、四级裁决金字塔、六灯/七灯双轨校验。
（本模板为简化版，由原 v4.3-CRO-P55-R2 单策略版优化修正而来：① 移除"六大新兴支柱产业双主线（硬科技/内需各≤3只、单主线≤50%）"旧架构，对齐 v5.0 开放式漏斗——A股个股为主进攻线、ETF为防守辐；② 资金架构改为三层资金（现金管理70-90%为真防守主力）；③ 新增 R-04波动率闸门 / F-35广度否决层 / R-05 S1确认制 三项建仓前置闸门；④ 评分改为个股24因子+ETF13因子双轨、灯改为个股六灯+ETF七灯；⑤ 得分门槛对齐 #167 个股独立70分、止损后重购≥85分。）

一、策略锚定

- 执行模式：AI辅助人工（AI负责规则裁决与格式化输出，用户手动下单）
- 定价模型：股价 = EPS × PE × MA60趋势溢价 × 情绪溢价
- 决策框架：四级不可逆裁决金字塔（层级1 > 层级2 > 层级2.5 > 层级3 > 层级3.5 > 层级4）+ 双轨灯校验（个股六灯 / ETF七灯）
- 评分体系：个股24因子（基本面40% + 趋势30% + 情绪10% + 微观10% + 风控10%）；ETF 13因子（宽基≥75 / 行业ETF≥78 进入候选池）
- 配置架构（v5.0 开放式漏斗）：A股个股=唯一主进攻线（STOCK_QUOTA=3只，组合大占比核心）；ETF=防守辐（宽基Beta/行业配置/债券货币稳定器，补位至总持仓≤5只、约2只ETF）
- 三层资金：进攻线0-10%渐进（B3模拟盘候选）+ 主引擎风险资产10-15%（台阶推进至10-30%，当前15%）+ 现金管理/国债ETF 70-90%（真防守主力）
- 仓位规则：个股初次建仓≤12%（MIN运算）、单票≤15%总硬上限、组合总持仓≤5只、现金管理70-90%（过渡期真防守主力）；ETF按13因子与MIN运算定仓
- 前置闸门（建仓第一前置，每日盘前判定）：①R-04波动率闸门（vol20<15禁一切新建仓 / ≥20禁S1/S2常规 / 15-20正常）②F-35市场广度否决层（BREADTH<15禁止新建仓，须与H1组合）③R-05 S1确认制（连续2日S1完整条件+标的连续2日站稳MA60+开盘涨幅≤1%）

四、分批次调仓计划（战术细化，须逐日重验前置闸门）

【T日（首日）】买入计划仓位的60%
- 9:25竞价涨幅＞2%标的当日停购（六灯第3灯）
- 须先通过R-04/F-35前置闸门；若为S1状态须R-05确认制通过
- 执行时段：13:00-14:30；算法执行：TWAP/VWAP（策略十四.7算法交易执行模块）

【T+1日（次日）】补足剩余40%
- 须重新满足当日前置闸门（R-04/F-35）+ ①竞价≤2%；②前1日涨幅≤5%且前3日累计≤10%；③信号时效性重评为A/B级（层级3.5 R值非C）
- 任一不满足则放弃该标补仓

七、AI输出格式要求

接收到上述数据后，输出：
1. 各标的层级1-3.5裁决结论（✅/❌）
2. 六灯（个股）/七灯（ETF）判定结果
3. MIN九项运算最终建仓/补仓比例（含MIN①-⑨逐项取值）
4. 前置闸门结论（R-04 vol20 / F-35 BREADTH / R-05 S1确认制）
5. T日买入股数、基准价、ATR止损价（个股P1=买入价−MIN(2×ATR,带宽%)；ETF E-P1=买入价×(1−带宽%)，公式不同禁止混用）

7. 组合合规校验总结论（持仓≤5 / 同行业≤2 / 单一行业≤30% / Beta≤1.2 / 风险贡献≤25%）
